# Getting help

- **Setting it up:** start with the [guides](README.md#documentation). The [reverse proxy guide](docs/reverse-proxy.md) has a section on fixing common problems.
- **Something doesn't work:** open a [bug report](../../issues/new?template=bug-report.md).
- **It works, or partly works, with your receiver:** please send a [receiver test report](../../issues/new?template=receiver-report.md). Reports from real receivers help the most.

Replace real IP addresses, MAC addresses, host names and passwords with example values before you post. This is a spare-time project, so answers can take a while. It has no connection to Denon, Synology or vTuner, so please don't ask them for support with it.
